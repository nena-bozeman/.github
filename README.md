# nena-bozeman

This organization hosts the source code for the **NENA (North East Neighborhood Association) Bozeman** website.

🌐 **Website:** [nenabozeman.org](https://www.nenabozeman.org/)

## About NENA Bozeman

The North East Neighborhood Association (NENA) is a community organization serving the northeast neighborhood of Bozeman, Montana. This GitHub organization contains the repositories used to build and maintain the association's public website.

## Tech Stack

- **[AstroJS](https://astro.build/)** — Static site framework used to build the website
- **Markdown** — Content is authored in Markdown for easy editing and maintenance
- **[Cloudflare](https://www.cloudflare.com/)** — Hosting and CDN for fast, reliable delivery
